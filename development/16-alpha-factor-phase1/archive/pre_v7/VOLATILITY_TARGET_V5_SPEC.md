# V5波动率目标风险机制冻结规范

冻结日：2026-07-31，结果运行前。本机制与已失败的MA200方向开关不同，只按事前波动预算连续调整仓位，不使用价格相对均线方向。

- 基础组合固定为V5的24月滚动回归风格合成；不再改因子权重、行业轮转或个股约束。
- 每个指数只使用截至信号日可见的自身日收盘收益，计算最近60个交易日年化实现波动率，至少40个观测。
- 年化波动目标固定15%；下期权益仓位=`clip(15%/实现波动率, 50%, 100%)`。历史不足时100%；现金收益固定0。
- 总月单边换手沿用冻结近似：`权益仓位*股票组合换手+abs(本期权益仓位-上期权益仓位)`；首期从现金建仓，双边5bp成本全计入。
- 只运行15%目标、60日窗口、50%下限这一组，不在看结果后搜索目标波动、窗口或下限。
- 分别报告全期、训练期和固定验证期的净超额、TE、IR、绝对回撤、换手；若全历史回撤仍超过20%或固定验证TE超过5%，本机制失败并保留证据。
