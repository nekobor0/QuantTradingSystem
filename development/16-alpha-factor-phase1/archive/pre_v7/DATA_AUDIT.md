# 阶段一数据审计（阻塞点快照）

审计日期：2026-07-29。数据库查询均为只读；`MvpSelect` 全程只读。

## 结论

当前生产库的未复权日线足以启动价格量价类因子研究，但不能直接完成用户要求的全部严检：复权因子尚未发布，行业分类和沪深300/中证500历史成分为空。复权因子可从现有 TDX raw 恢复；TDX `VolInStock` 全为 0，不能恢复流通市值。MvpSelect 有一份可用作规模中性化候选的历史总市值文件。行业和指数历史成分仍需要补充数据权限或用户提供文件。

## TDX raw 全量审计

- 实际扫描 8,845 个 JSON、2,861万行（含重复抓取），解析出 7,141 个唯一证券；8 个被拒绝文件均为 ETF/基金响应缺少日线字段。
- 对导出清单中的 5,542 个 A_SHARE，选中 5,533 个最长历史响应，覆盖率 99.84%；缺失的 9 只均不在生产库。选中数据 14,916,622 行。
- 选中 A 股的 `ForwardFactor` 行覆盖 100%，全部证券最后一个因子为 1，随除权事件阶梯变化，符合前复权乘数形态；例如 `600061.SH` 2005–2026 共 5,047 日、13 个因子水平，范围 0.355789–1.0。
- `VolInStock` 字段形式上无缺失，但 14,916,622 行全部为 0，正值覆盖率为 0%；不得用于流通市值或规模因子。
- `000001.SZ` 抽样显示：MvpSelect Baostock 因子在 2020 年发生明显口径/尺度断点；2021 年后按同一日期归一后的变动比率与 TDX 基本一致。因此不能把 MvpSelect 归档因子不经清洗直接入库，TDX raw 更适合作主源、Baostock 仅作事件日抽查。

机器可读证据：`artifacts/alpha_phase1/tdx_research_raw_audit.json`。复跑命令见 `scripts/alpha_phase1/audit_tdx_research_raw.py`。

## 历史总市值候选

- `MvpSelect/data/expanded/financials/akshare_total_mv.parquet`：4,274,526 行、5,428 只证券，1990-12-20 至 2026-06-05，键 `(symbol,date)` 无重复、三列均无空值。
- 2015 年后共 138 个月；最近 36 个月每月覆盖 5,039–5,197 只，月度中位数 5,115.5 只。原始相邻观测间隔中位数 3 天、95 分位 16 天。
- 字段为 `total_mv_yi`（亿元）。正式使用前仍需抽样验证单位、发布日期/抓取方式和极端值；但其历史日期粒度足以构造月末 `log(total_mv)` 规模暴露。

## 不能直接使用的旧资产

- `MvpSelect/data/archive/adj_factor.parquet` 只有 842 行、83 只证券，且只是公司行动日，不是全市场逐日因子。
- `MvpSelect/data/expanded/daily` 大量文件的 `adj_factor` 固定为 1.0；有些 OHLC 已在接口侧复权，不能与生产库 RAW 混用。
- `MvpSelect/data/expanded/sector_stock_list.csv` 有 5,529 行，但行业是当前截面，不是 point-in-time；名称/部分行业文本还包含不可逆替换字符，不能作为历史行业中性化依据。
- 当前 5,533 只 A 股来自当前清单，缺历史退市证券，存在幸存者偏差。近 3 年样本外影响需要另行量化，全历史结论必须带限制。

## 接口探测

- 现有 Tushare 凭证访问 `index_weight`：明确返回“没有接口权限”。
- 同一凭证访问 `index_classify`：明确返回“没有接口权限”。
- `stock_basic` 请求返回 0 行，不能作为补充行业源。
- AkShare 本机接口 `index_stock_cons_csindex`/`index_stock_cons_weight_csindex` 仅提供最新成分，不接受历史日期参数；用当前成分回填历史会制造未来信息。
- 中证指数官网能找到半年度样本调整公告，可作为公开替代源，但从当前成分反向重建至少近 3 年仍需逐期下载、解析并核验；在用户决定是否提供付费权限/现成文件前未继续批量抓取。

## 必要补充及优先级

1. **必须**：申万或中信行业的 point-in-time 成员，至少覆盖研究期，字段含证券代码、行业代码/名称、`in_date`、`out_date` 或等价生效区间。
2. **必须**：沪深300（000300.SH）和中证500（000905.SH）历史成分，至少覆盖近 3 年样本外，最好覆盖全研究期；字段含指数代码、证券代码、生效日期、失效日期/调整批次。
3. **建议**：历史退市 A 股主数据与日线，减少幸存者偏差；若暂缺，阶段一可先完成近 3 年并明确降级。
4. **无需外部补充**：复权因子可从 TDX raw 恢复；规模暴露可优先验证并使用本地 AkShare 历史总市值候选。TDX 流通股本字段不可用。
