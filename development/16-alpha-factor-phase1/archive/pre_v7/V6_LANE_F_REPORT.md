# Lane F 行业轮动报告：相对动量有收益，但回撤、容量和跨基准边际失败

## 技术摘要

`industry_relative_momentum_v6` 已完成正式研究，决定为 `REJECTED`。行业层信号的1个月Rank IC为0.0671、HAC t=1.176；前5行业等权配置取得4.11%年化净超额。但IR仅0.335、主动最大回撤-16.30%，1000万元最低容量约396万元。将其主动收益以20%叠加到增强基线时，中证1000 IR提高0.224，而沪深300 IR下降0.223，缺少跨基准稳定的边际价值。

## 行业信号方向为正，强度仍不足

- 1个月平均行业Rank IC：0.0671。
- HAC t：1.176；双侧p=0.2397。
- 全局BH q=0.4540。
- 31个PIT一级行业、83个可形成11月历史的信号月；未来信息违规0。

信号满足事前的方向和最低t门槛，但p/q不支持强显著结论。

## 配置收益为正，但风险调整后表现不合格

| 指标 | 结果 |
|---|---:|
| 年化净超额 | 4.11% |
| IR | 0.335 |
| TE | 12.92% |
| 主动最大回撤 | -16.30% |
| 月均单边换手 | 27.80% |
| 月度主动胜率 | 51.43% |
| 上涨市场月均主动收益 | +0.68% |
| 下跌市场月均主动收益 | +0.03% |

收益几乎全部来自上涨月份；下跌月份的主动改善接近零，不能承担组合防御职责。

## 方法只衡量行业配置，没有夹带个股选股

每个行业月收益由当月PIT成员中可交易股票等权计算。当前信号只使用 `exit_date<=signal_date` 的最近11个已实现月复合收益，再减31行业截面均值。每月选择最高5个行业、各20%；行业内部持有全部可交易成员等权。比较基准为31行业等权、行业内部同样等权。

## 冻结门槛在IR、回撤、容量和边际叠加上失败

| 门槛 | 结果 |

| 年化净超额>3% | PASS，4.11% |

| 对两增强基线20%叠加ΔIR均>0 | FAIL；沪深300 -0.223，中证1000 +0.224 |

## 决定与下一步边界

简单行业相对动量对小盘增强可能有互补性，但对大盘增强明显冲突，且主动回撤和容量不足。正式决定为 `REJECTED`，无影子写入。禁止结果后改成6个月、减少行业数或只保留中证1000结果。若 Lane F 继续，GOAL 允许的下一独立机制是行业盈利增速/扩散，必须重新 leader 对齐。
