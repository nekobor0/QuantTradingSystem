# Lane E 股票动量报告：行业残差动量有弱IC，但独立组合不稳定

## 技术摘要

`industry_residual_momentum_v6` 已完成正式研究，决定为 `REJECTED`。剥离行业、规模、Beta和残差波动率后的12-1动量，在固定验证的3个月标签上平均Rank IC为0.0203、HAC t=1.087，方向和最低t门槛勉强通过。但50股组合年化净超额只有2.62%、Sharpe 0.548、最差月-23.55%、最大回撤-29.85%，同时未通过单股集中和1000万元容量。弱截面预测没有转化为可独立运行的动量策略。

## 信号方向为正，但未达到统计稳健性

- 3个月平均 Rank IC：0.0203。
- HAC t：1.087；双侧p=0.2772。
- 全局BH q=0.5160。
- 可交易池残差信号覆盖93.86%；重复键0、未来信息违规0。

HAC t刚超过事前最低1.0，但p/q均不支持强统计结论。该证据只允许说“方向弱正”，不能说动量Alpha已被独立验证。

## 组合收益不足以补偿高波动和尾部损失

| 指标 | 结果 |
|---|---:|
| 组合年化收益 | 15.71% |
| 全A等权年化收益 | 13.08% |
| 年化净超额 | 2.62% |
| Sharpe | 0.548 |
| IR | 0.225 |
| TE | 22.41% |
| 最大回撤 | -29.85% |
| 最差月 | -23.55% |
| 月均单边换手 | 42.35% |

20bp成本压力后净超额仍为正，说明失败不是单纯手续费造成；核心问题是收益幅度不足、回撤和单月尾部过大。

## 方法保持为“行业内相对趋势”，没有复用普通Momentum结论

原始信号固定为12-1 Momentum；每月1%/99%截尾和标准化后，对行业哑变量、log市值、Beta及残差波动率做截面OLS，残差为正式信号。组合每月持有残差最高的50股、每行业最多5股，T+1复权开盘执行。3个月标签只用于评价，不参与当期残差估计。

## 决定与下一步边界

本结果没有测试6-1、基本面动量、低拥挤或崩溃保护，因而不能外推这些不同机制；也不能在看到最差月后临时加入保护层。正式决定为 `REJECTED`，无影子写入。若 Lane E 继续，只能按 GOAL 下一个优先方向“基本面动量”重新 leader 对齐，而不是修改本轮回看期或股票数。
