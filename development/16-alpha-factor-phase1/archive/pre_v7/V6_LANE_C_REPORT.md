# Lane C 基本面选股报告：Quality-adjusted Value 有信号，但容量与单股集中不合格

## 技术摘要

`quality_adjusted_value_v6` 完成了集中式基本面策略的完整研究闭环，正式决定为 `REJECTED`。信号层具有正向信息：固定验证完整标签样本的6个月 Rank IC 为0.0847，HAC `t=1.93`。30股组合也取得12.19%的年化净超额和0.94的Sharpe，最大回撤优于全A等权基准。但1000万元容量门槛严重失败，最低容量约74万元且有6笔交易超过5% ADV；最大单股贡献占累计超额26.1%，超过20%上限。收益证据不能覆盖可交易性和集中度失败。

## 信号有效，但统计证据尚未通过全局 FDR

- 6个月平均 Rank IC：0.0847。
- HAC t统计量：1.929；双侧 p=0.0538。
- 纳入历史试验账本后的 BH q=0.1457。
- 固定验证的完整6个月标签只使用到2025-12-31；2026年尚未兑现的6个月收益不进入信号检验。

这支持“低质量惩罚可以降低价值陷阱”的方向性判断，但不能宣称经过多重检验后显著。

## 30股组合收益较强，但 TE 和年份路径波动很大

固定验证期2023-07-01至2026-06-30，基准为同月同可交易全A股票池等权收益。

| 指标 | 结果 |
|---|---:|
| 组合年化收益 | 25.27% |
| 全A等权年化收益 | 13.08% |
| 年化净超额 | 12.19% |
| Sharpe | 0.938 |
| IR | 0.571 |
| TE | 16.91% |
| 组合最大回撤 | -12.65% |
| 基准最大回撤 | -23.04% |
| 月均单边换手 | 14.95% |

年度主动收益加总为：2023下半年+37.55%、2024年+5.91%、2025年-11.25%、2026上半年-4.04%。结果强烈依赖验证初期，后两段已经转负，是实时时序稳定性的明确风险。

## 数据、公式和组合规则均按事前登记冻结

- PIT面板554,400行、5,775股、96月；重复键0、未来信息违规0。
- 可交易股票中原始信号覆盖88.52%。
- 原始公式为 `Value_z - max(-Quality_z, 0)`：只惩罚低质量，不给高质量额外加分。
- 30股等权，季度冻结排名；单行业最多6股。
- 每月最新PIT质量低于-1或不再满足交易条件时退出；不可交易的持仓不会假设成交。
- 保存了 raw、winsorized、standardized 和行业/规模 neutralized 信号；正式集中式选股使用 raw 经济分数。

## 冻结门槛显示容量和单股归因不可接受

| 门槛 | 结果 |

最大正贡献股票为 `920357.BJ`，累计毛贡献约7.35个百分点；其后若干北交所小盘股同样贡献较高。信号把组合推向估值低、质量尚可但流动性有限的小盘股票，这与容量失败方向一致。

## 限制、决定与唯一后续方向

全A等权基准是覆盖匹配基准，不是可直接交易的官方指数；这使相对收益更适合研究归因而非产品跟踪。单股贡献分母为组合累计主动收益、分子为单股毛贡献，因此是保守集中度门槛。即便改用更宽松定义，74万元最低容量仍足以阻止影子晋级。

正式决定：`REJECTED`，不写实时影子。禁止事后修改股票数、行业上限、质量阈值、持有期或剔除北交所。若 Lane C 继续下一构造，必须按 GOAL 选择独立的“盈利意外×反应不足”机制并重新 leader 对齐；不能把本轮改成大盘股票池后当作同一次试验。
