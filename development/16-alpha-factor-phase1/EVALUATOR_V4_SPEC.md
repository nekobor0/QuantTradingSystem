# 分类评价器 V4 冻结规格：T+1开盘与扩展风格模型

状态：2026-07-30冻结，先于任何V4收益结果生成。约束来源以《因子动物园第二轮反馈》为主，并执行用户新增裁决：买入价由T+1收盘改为T+1开盘。

## 交易标签

- 所有V4候选统一使用T日收盘后已知信号、T+1开盘买入；短周期/事件因子仍在原先冻结的第h个持有日收盘退出，月频因子仍在下一调仓周期原退出日收盘卖出。只改买入价格，不改方向、核心窗口、阈值或样本切分。
- T+1停牌、零成交或全天一字涨跌停视为无法在开盘获得可执行成交；其他开盘使用复权开盘价。旧V3的T+1收盘结果永久保留并明确标注，不能与V4混用。
- V4输出使用独立文件名，不覆盖V3面板和机器结果。若开盘口径使旧候选改变结论，只报告口径敏感性，不把它包装成独立新因子。

## 扩展风格风险模型优先于新Alpha

下一阶段先建立并审计以下基线，均为风险模型/归因变量，不计入“至少5个新Alpha”：

1. Size：对数流通市值；Nonlinear Size：对行业及线性Size回归后的对数市值平方残差。
2. Beta：至少120个有效交易日、252日滚动股票收益对全A等权市场收益回归斜率。
3. Momentum：12-1动量；Short-term Reversal：过去20日收益取负。
4. Liquidity与Residual Volatility：自由流通换手和60日波动。
5. Value Composite：盈利公司内部E/P、B/P、S/P、股息率行业标准分等权；亏损公司使用独立`loss_dummy`，不得把亏损E/P记0后混排。
6. Investment：保守资产增长与权益增长等权基线。
7. Quality与Leverage：季度PIT财务数据补齐后构建；在此之前标记`DATA_BLOCKED_PARTIAL`，不得把年度低覆盖代理称为完整Quality。

财务基线至少区分非金融、银行、券商、保险；普通毛利、CFO和资产负债率不得直接跨金融与非金融混排。`gross_profitability`专指毛利润TTM/平均总资产，毛利润/收入必须命名为`gross_margin`。

## 慢变量评价

- Value、Quality、Investment按月调仓，核心收益窗口固定3个月；1、6、12个月只作诊断。季度财务从`ann_date`后首个交易日生效，保留当时可见版本。
- 风格基线评价目标是覆盖、稳定性和风险解释能力，不用新Alpha的尾部收益门槛判死刑。
- 新Alpha继续沿用V3物种门槛，但Pure中性化扩展为行业、线性/非线性市值、Beta、波动、流动性、动量、短期反转、Value、Quality、Investment、Leverage。缺失的风格维度必须显式报告，不能简称“完整Pure”。

## 新研究优先级与停止线

1. 先完成扩展风格基线和数据质量报告。
2. 再研究季度盈利意外/预告/快报与公告反应不足，训练截止2023-06，2023-07后固定样本外。
3. 再研究可证明完整的解禁、指数调样等预定供需冲击，并优先用潜在股份/ADV20衡量压力。
4. 最后研究`ResidualValue`、质量合理价格和现金流意外×反应不足。

停止继续微调Formulaic窗口、简单大小单流、回购完成、单纯股东增持、静态户数变化及月频融资流。除非获得新字段并提出新的主体—冲击—摩擦机制，否则维持原状态。
