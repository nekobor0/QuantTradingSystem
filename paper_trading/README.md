# 模拟仓 v2（75% 股息 + 25% 波动率趋势）

本地、只读市场数据的模拟交易系统。固定安全开关为 `TRADING_MODE=paper`、`ALLOW_LIVE_TRADING=false`、`ENABLE_ORDER_SUBMISSION=false`；代码中没有券商下单适配器。

## 执行口径

- 收盘后产生目标计划，下一交易日开盘撮合，不允许同收盘价成交。
- A 股 100 股整手；佣金万 1.2、单笔最低 5 元；卖出印花税在 2023-08-28 前为千 1、之后为万 5。
- 现金分红在股权登记日确认权利、派息日入账；卖出时按 FIFO 持有期结算红利税（30 日内 20%、一年内 10%、一年以上 0%）。
- 月末按交易所日历调仓；缺失开盘价时保留原持仓与待执行计划，不以零价删除。
- 标的至少上市 180 天、20 日平均成交额不低于 100 万元，排除 ST/退市及北交所标的。
- 组合达到硬回撤线时，明确动作是将波动率分仓目标降至现金；风险控制不会被绕过。

## 首次升级

旧版 `state.json` 中的持仓没有真实成交成本和 lot 记录。v2 会保留它作为诊断证据并标记 `legacy_import=true`，同时硬阻断后续执行。先备份旧文件，再从前端点击“重置 v2 模拟仓”或调用 `/api/reset`。原先两个交易日的数据不能当作 v2 的有效影子验证样本。

## 运行

在仓库根目录执行：

```powershell
python -m paper_trading.app
```

打开 `http://127.0.0.1:8000`。页面显示净值、待执行计划、风险状态与本地成交审计。盘后流程为：更新数据 → 执行上一交易日计划（若有）→ 分红记账 → 收盘估值 → 生成下一开盘计划。

## 验证

```powershell
python -m pytest -q tests/paper_trading
python -m paper_trading.p1_validation --data-root <research-data-path>
```

P1 的结果和限制见 `P1_VALIDATION.md` 与 `p1_results.json`。P1 是历史可执行性验证；P2 需要更长时间的前向影子运行、外部成交/持仓对账、任务健康度与异常告警，不能由两天本地净值记录替代。
