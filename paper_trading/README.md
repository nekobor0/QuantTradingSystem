# 模拟仓系统（75% 股息 + 25% 波动率+趋势）

本地模拟仓 + 每日盘后自动更新 + 调仓信号 + Web UI。与自己的交易软件并行执行。

## 目录结构

```
paper_trading/
├── checklist.md           # 执行规则 checklist（先读这个）
├── config.py              # 配置（本金/分仓/阈值/成本/风险线）
├── state.py               # 状态管理（持仓/现金/净值，JSON 持久化）
├── data_update.py         # 每日盘后数据更新（tushare）
├── strategies.py          # 两个分仓的每日执行逻辑（扫描+信号+本地成交）
├── app.py                 # Web UI 后端（FastAPI）
├── templates/index.html   # Web UI 前端（ECharts）
├── data/                  # 落盘数据（自动生成）
└── state.json             # 模拟仓状态（自动生成）
```

## 快速开始

### 1. 每日盘后更新数据（可选，Web UI 会自动做）
```bash
cd paper_trading
python data_update.py 20260817   # 传入交易日 YYYYMMDD，默认今天
```
更新：全市场行情（open/close/amount/vol）、估值（pe_ttm/dv_ttm/circ_mv）、分红事件、上证指数/沪深300。

盘中执行（当日日线未定稿）会自动回退到最近已收盘交易日；首次运行自动回填约 70 个交易日行情预热 amihud20。

### 2. 启动 Web UI
```bash
cd paper_trading
python app.py
```
浏览器打开 http://127.0.0.1:8000

### 3. Web UI 功能
- 看板：生效交易日、总净值、累计收益、两个分仓净值、波动率分仓仓位。
- 净值曲线：组合 + 股息 + 波动率 + 基准；可切换日/周/月/年；可高亮最大回撤。
- 基准：上证指数 / 沪深300 / 无。
- 按钮：「执行当日」（更新数据+扫描+本地成交+记录净值）、「扫描信号」（只看信号）、「更新数据」、「重置模拟仓」（清空持仓与净值历史，需二次确认）。

## 每日流程（与 checklist 对应）
1. 盘后点「执行当日」→ 自动更新数据 + 生成两个分仓的调仓信号 + 本地成交 + 记录净值。
2. 在 Web UI 看「调仓信号」表，按买入/卖出/复投清单，在本地模拟仓 + 你自己的交易软件执行。
3. 记录实际成交价，回填到 state.json（或后续扩展成自动回填）。

## 关键说明
- 因子用可实时计算的代理：价值=EP(1/pe_ttm)、非流动性=amihud20、分红=dv_ttm，与历史回测的 value_composite 有差异，模拟仓阶段需对比校正。
- 复投版本 = 复投到原股（股息除权日现金复投回原股票）。
- 成本口径：印花税万分之五（卖出）+ 佣金万分之一点二（双边）；未计滑点与股息红利税。
- 风险线：绝对回撤 -20% 告警、-25% 减仓（在 Web UI 观察，未自动执行）。
- 趋势信号 MA_N=250 在净值历史不足 250 日时保持满仓（向前预热，属正常）。
